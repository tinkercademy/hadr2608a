What each scenario drills

The catalogue students see (list_scenarios) carries flavour only: modality and mood, no mechanics. This is the instructor-facing version - what is actually in each scenario and what it is meant to teach.

Scenario What is in it The lesson
stage1-basic Perfect structured reports: three fires, two trucks. Rank by people at risk, not by reported severity alone.
stage2-language Free-text calls around two real fires, one loud false alarm, and a cat-in-a-tree. Extract the claim; do not spend a truck on smoke.
stage3-partial An alarm and a smoke call for the same block, a duplicate, a wrong address, and a delayed second fire. Merge before you dispatch.
stage4-replan A responder correction, contradictory headcounts, and a big new fire that ignites while both trucks are committed. Revise the plan.
stage5-triage High call volume with uncertain times and a wrong address; a crowded building burns but is claimed only medium severity. Reach it before it collapses; do not trust the loudest or the latest.

Submission list

What each chapter expects to come back. Chapters with neither column (background, HADR intro, tokens) are omitted. “Merge as code” always means a pull request into the participant’s own master, approved by a teammate; the only cross-repository pull request is the one marked as such.

“Work” is how the chapter is actually run, taking the broadest mode it contains: group if any part is decided or performed together, pair if two people have to produce something jointly, otherwise individual. Every merge is reviewed by a teammate regardless - that is the standing rule, not a mode, so a chapter is never pair work merely because someone reviews the pull request.

Running many sessions in parallel

The engine writes run logs to a machine-wide state dir (~/.local/state/hadr-engine/ by default), so parallel graders/students share one pile of run-*.jsonl files. Each run still gets a unique filename, but set HADR_ENGINE_STATE_DIR to a per-session path to keep logs isolated and easy to find. The no-LLM runner smoke test already spawns its engine on a free ephemeral port, so it never collides with a dev engine on 8000.
