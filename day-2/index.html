Day 2

Build, evaluate, and apply

Day 2

On Day 2, you build the common agent loop and add quality gates. You then complete the HADR system. You use test results to improve it. Finally, you use the course techniques in a team LLM app.

Complete the HADR pipeline

Each stage includes a prompt for Claude Code. Claude reads the repository, makes a focused change, and runs checks. You must review and understand its decisions.

  1. Agentic loop: build the common tool loop. Test it with example tools and a real model.
  2. Quality gates and integration: add automated checks, merge open work, and record a baseline run.
  3. Stage 1: dispatcher: configure the loop with state, instructions, and typed tools.
  4. Stage 2: intake: build one text-to-structure model call and evaluate it.
  5. Stage 3: reconciliation: integrate the supplied deterministic solution.
  6. Stage 4: replanning: make one measured change for new evidence.

Evaluate and apply

  1. Model comparisons: compare models against the same evidence instead of choosing by reputation.
  2. Build an LLM-based app: as a team, build one application and apply three course techniques.
  3. Prepare the presentation: prepare to present the work to the class with your group.
  4. HADR finale: return to the HADR agent for the final group run.

The aim is not to build every possible HADR feature. The aim is to understand the complete system and use its techniques in a new app.
